## KleopatraKindomTweaker (KTweaker)

Твикер для Windows на C# / WPF (.NET 8): системные твики, очистка, менеджер
процессов, установка/удаление встроенных UWP-приложений и базовая защита от
программ-вымогателей — всё в одном окне.

## Возможности

- **Панель** — сводка по системе (ОС, CPU, RAM, GPU) и кнопка «Быстрая
  настройка», применяющая набор рекомендуемых твиков в один клик.
- **Безопасность** — живой статус Защитника Windows (реальное время, антивирус,
  возраст баз) и 8 переключателей защиты от шифровальщиков и блокировщиков
  экрана: Controlled Folder Access, профильные правила ASR (в т.ч. отдельное
  правило именно против ransomware), SmartScreen, брандмауэр для частных и
  публичных сетей, безопасный уровень UAC. Кнопка «Защитить сейчас» включает
  всё разом.
- **Системные твики** — 118 переключателей для документированных ключей
  реестра по 9 категориям: Персонализация, Приватность, Производительность,
  Игры, Windows Update, Система, Сеть, Реклама и предложения, Безопасность
  (последняя вынесена на отдельную вкладку и не дублируется здесь). Есть
  «Выбрать все» / «Снять все».
- **Менеджер процессов** — список процессов с памятью, завершение и
  повышение приоритета.
- **Очистка системы** — асинхронное сканирование и очистка
  temp/prefetch/кэша миниатюр/логов Windows Update; недоступные подпапки не
  останавливают процесс, прогресс виден по каждой цели.
- **Установка/удаление UWP** — реальная проверка результата (а не просто код
  возврата PowerShell): удалённое приложение можно переустановить обратно без
  интернета, если Windows ещё хранит его файлы, иначе откроется страница
  Microsoft Store.
- **Инфо о системе** — CPU/RAM/GPU/материнская плата/диски через WMI.
- **Настройки** — тема (тёмная/светлая), язык интерфейса (русский/английский/
  украинский), блок «О программе».

## Языки и сохранение настроек

Интерфейс переключается между русским, английским и украинским без
перезапуска. Тема и язык сохраняются при закрытии окна в
`%AppData%\Roaming\KleopatraKindom\TweakerConfig.conf` (обычный текстовый файл
вида `Ключ=Значение`) и подхватываются автоматически при следующем запуске.

## Сборка

Запустить `build.bat` из корня проекта (нужен .NET 8 SDK, Visual Studio не
требуется). Скрипт сам проверяет версию SDK, чистит старый `publish`, после
чего собирает и публикует проект одной командой.

Результат: `publish\Tweaker.exe`.

**Важно:** сборка framework-dependent (небольшая, несколько МБ) — для запуска
на компьютере пользователя нужен установленный **.NET 8 Desktop Runtime**.
Сам по себе `Tweaker.exe` без рантайма не запустится; для распространения
собирайте установщик (например, через Inno Setup), который проверяет и при
необходимости ставит рантайм автоматически.

Приложение запрашивает права администратора при запуске — большинство твиков
пишут в защищённые ветки реестра.

## Структура проекта

```
Pages/        — страницы (Dashboard, Security, Tweaks, ProcessManager, Cleanup, UwpApps, SystemInfo, Settings)
Services/     — вся логика (RegistryTweakService, CleanupService, ProcessService,
                UwpAppService, SecurityStatusService, SystemInfoService,
                LocalizationService, AppSettingsService)
Models/       — TweakItem
Themes/       — Dark.xaml / Light.xaml / Controls.xaml
```

Чтобы добавить новый твик: один блок в `RegistryTweakService.BuildCatalog()`
со стабильным `Key` + пара строк перевода (`<Key>_Title` / `<Key>_Desc`) в
`LocalizationService.cs` на всех трёх языках.
