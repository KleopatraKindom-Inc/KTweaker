## KleopatraKindomTweaker

## Возможности
- **Панель** — сводка по системе + кнопка «Быстрая настройка» (набор рекомендуемых твиков в один клик).
- **Системные твики** — переключатели для реальных ключей реестра: тёмная тема, расширения файлов,
  скрытые файлы, классическое контекстное меню, телеметрия, рекламный ID, Cortana, веб-поиск в Пуск,
  анимации окон, прозрачность, Power Throttling, Game DVR, ускорение мыши.
- **Менеджер процессов** — список процессов с памятью, завершение и повышение приоритета.
- **Очистка системы** — сканирование и очистка temp/prefetch/кэша миниатюр/логов Windows Update.
- **Инфо о системе** — CPU/RAM/GPU/материнская плата/диски через WMI.
- **Настройки** — переключение тёмной/светлой темы.

## Сборка

Запустить build.bat
Файл программы будет publish\KleopatraKindomTweaker.exe
